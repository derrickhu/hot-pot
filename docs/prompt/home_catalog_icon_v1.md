# 首页图鉴入口图标 v1（无按钮框）

Generate one single standalone icon for a mobile casual fruit game home screen.

Use the provided home screen screenshot as style reference. The icon is for the fruit catalog / collection entry.

## Content

- A simple, clear "fruit catalog" icon.
- Main shape: an open illustrated book or fruit album, slightly tilted, with 2-3 large fruit symbols/pages visible.
- Optional small fruit decorations: one strawberry or lemon slice, but keep details minimal.
- No text, no Chinese characters, no English letters, no numbers.
- No rectangular button base, no pill button, no label panel, no background card.

## Style

- Cute 2D casual mobile game UI, matching the "别捞水果" home screen style.
- Bright, readable, thick hand-painted outline.
- Icon should be obvious at small size.
- Use simple shapes and high contrast:
  - cream / light blue book pages
  - teal or dark blue-green outline
  - red strawberry / yellow lemon / green leaf accents
- Polished, soft, slightly glossy, but not heavy 3D.

## Output

- Transparent background PNG if supported.
- Centered icon only.
- Clean edges, no shadowy rectangular base, no button frame, no extra text.
