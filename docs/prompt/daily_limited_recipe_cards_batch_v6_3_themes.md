# Daily Limited Recipe Cards Batch v6 3 Themes

新增 3 个每日限定主题菜谱卡，不能使用用户截图原图，只参考饮品主题和制作方向，按游戏现有每日限定菜谱卡风格重新生成。

## 通用约束

- 9:16 竖版。
- 可爱手绘移动游戏菜谱卡 UI 风格，圆角奶油色内卡、柔和水果背景、大标题、副标题胶囊、材料小图标区、步骤卡区。
- 上方饮品主图不能太大，只占整张卡高度约 28% 到 32%，最多不超过 35%。
- 底部步骤区域必须占整张卡高度约 32% 到 38%。
- 每个步骤卡都必须带独立小插画图标，不能只有文字。
- 步骤图标要表达对应动作：切水果、倒入饮品、加燕麦、搅拌、加冰等。
- 禁止照片风、截图风、硬 3D、二维码、水印、英文。
- 中文完整、清晰、可读。

## 主题 1：蜜瓜燕麦拿铁

- 目标水果：蜜瓜
- 材料：蜜瓜、燕麦、牛奶、咖啡、薄荷、冰块
- 步骤：
  1. 蜜瓜切成小块
  2. 杯底加入蜜瓜泥
  3. 倒入牛奶和冰块
  4. 加入咖啡液
  5. 撒上燕麦点缀
  6. 放蜜瓜片完成

## 主题 2：芭乐油柑饮

- 目标水果：芭乐、油柑
- 材料：芭乐、油柑、柠檬、绿茶、糖浆、冰块
- 步骤：
  1. 芭乐切块备用
  2. 油柑压汁
  3. 杯中加入芭乐
  4. 倒入绿茶和油柑汁
  5. 糖浆调甜味
  6. 加冰摇匀完成

## 主题 3：木瓜牛奶

- 目标水果：木瓜
- 材料：木瓜、牛奶、红枣、冰糖
- 步骤：
  1. 木瓜去皮切块
  2. 红枣煮出甜味
  3. 加入木瓜和冰糖
  4. 倒入牛奶小火煮
  5. 稍微放温
  6. 倒杯完成
