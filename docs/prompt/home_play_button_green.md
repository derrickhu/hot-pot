# 首页主按钮：绿色无字药丸 + 水果边饰

与 `docs/prompt/home_summer_background.md`、`home_bg_summer.jpg` **同屏配色**：底图为 **薄荷青 / 冰蓝** 清爽调，按钮用 **偏薄荷的鲜绿**（约 `#5ed99a`～`#6ecf9e` 主填充，略深 `#3a9d6e` 描边或下沿轻阴影），**不要**荧光刺黄绿、**不要**暗沉军绿；整体像 **青柠皮 + 薄荷叶** 的清凉感，与底图融在一起。

---

## 造型

- **横向大圆角药丸**（约 16:5～18:5 宽高比），**无文字、无数字、无 Logo**。
- **线稿**：清晰细至中等深灰绿 / 深青绿描边，**2D 手绘卡通**水果游戏风，与首页西瓜柠檬插画笔触一致。
- **边饰**：角上或长边外缘轻探出 **小西瓜片、柠檬或青柠片、两三片薄荷叶**（体积小、不挡中间大面积留白，方便程序叠关卡标题）；装饰与按钮同套线稿。
- 药丸外 **透明底**；装饰可略超药丸外轮廓，整体仍紧凑。

---

## 画幅与路径

- 建议约 **560×200** 或 **640×220**（可 2x 导出）。
- 进包：`assets/images/home_play_btn.png`
- 抠图裁边：见 `docs/生图与资源流程规范.md`
