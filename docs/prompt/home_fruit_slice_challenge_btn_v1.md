# 首页「果切挑战」主按钮贴图（与关卡按钮同风格、换色）

## 用途

微信小游戏首页：与「第 N 关」绿色药丸按钮**同一套 UI 语言**（粗描边、立体高光、横向圆角药丸），但**换一套暖色**（橙黄 / 蜜橘渐变），用于「果切挑战」入口。**画面上不要出现任何文字**（标题由程序叠字），便于多语言与字号调整。

## 技术规格

- 透明背景 PNG
- 横向圆角胶囊按钮，**宽高比约 3.4:1**（与常见主 CTA 药丸一致）
- 分辨率约 **880×260** 或同比例（程序会缩放到与关卡按钮相同逻辑宽度）

## 画风

- 2D 休闲手游 UI，**可爱、圆润、略 3D 凸起**
- 填充：**上浅下略深**的蜜橘 → 杏黄纵向渐变，明亮清爽
- 外轮廓：**粗深色描边**（深橙褐或深棕），内缘可有一条细浅色高光边
- 中央略亮的高光带（像玻璃釉），**不要**画文字、图标、emoji
- 与「夏日水果、别捞水果」主界面气质一致，**不要**写实照片、不要扁平无描边 Material 风

## 禁止

- 任何中文、英文、数字、Logo、水印、刀叉小图标
- 与关卡贴图完全同色的绿药丸（必须明显区分色温）

## 进包后处理（定稿）

生图母版若带灰底/杂底，在仓库外或 `.tmp_asset_work/` 中走 **rembg**（如 `birefnet-general-lite`）抠透明，再执行本仓库 `scripts/trim_alpha_bbox.py` 裁净透明边，最后拷贝为 `assets/images/home_fruit_slice_challenge_btn.png`。首页文案「果切挑战」由程序叠字，与 `home_play_btn` 上「第 N 关」同款描边。
