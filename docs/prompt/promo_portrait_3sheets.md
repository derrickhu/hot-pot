## 共用版式（参考 huahua）

- 整张是一个**圆角厚边相框**，相框 outline 颜色按主题（黄/暖橙）柔和暖调，与游戏首页竹屋暖色保持一致。
- 相框四角散落小装饰：草莓 / 柠檬片 / 橙片 / 葡萄 / 猕猴桃片 / 闪光星 / 金币若干，**不要遮主体**。
- 相框内部：上 2/3 是核心玩法画面（仿手机内游戏界面，但是经过艺术化重组，不是直接截图）。
- 下 1/3 一条**白色卷轴 / 飘带**横穿，飘带上是**大号粗体中文标题**（黄色填充 + 红橙色描边 + 深褐外描边，类似 huahua 的"合成鲜花"），下面一行小字副标题（白底 + 红色或暖橙描边）。
- 中文必须**完整、笔画清楚、四到五字**，禁止糊字、缺字、错字。
- 整体配色：**奶白 / 暖黄 / 草莓红 / 橙色 / 薄荷绿** 点缀，背景同色系大色块以确保缩略图可读。

## 各图设计

### 竖图1：主玩法（三连消水果）
- 文案：
  - 主标题：**鲜果三连**
  - 副标题：**越捞越上头**
- 画面要点：
  - 上方仿游戏内"收集格"一排（圆角矩形托盘 3 个，每个托盘上 3 颗同种水果飞入并合并发光）。
  - 中央一个超大正面浅紫色/奶白大碗，碗里满满水果切片（草莓厚片、橙片、柠檬片、香蕉段、葡萄、猕猴桃片、芒果丁），三颗一组的水果在飞舞，金色 sparkle、连线特效。
  - 不画手指、不画 UI 按钮文字，但保留"收集托盘"作为玩法暗示。

### 竖图2：解锁百果图鉴
- 文案：
  - 主标题：**百果解锁**
  - 副标题：**关关有新鲜**
- 画面要点：
  - 中央是一面"水果图鉴墙"——4×4 或 3×4 的卡通圆角小卡，每张卡上画一种水果（苹果/香蕉/葡萄/猕猴桃/草莓/橙子/柠檬/西瓜/芒果/桃子/蓝莓/菠萝），其中**1~2 张是问号未解锁**（剪影 + 锁/问号），**主解锁刚刚点亮**的一张周围金光四射、丝带飘动。
  - 顶部加一个奶白色"图鉴本"的封面感（小书脊、丝带书签）。
  - 不要写"图鉴""LOCKED"等英文/UI 字。

### 竖图3：冰爽关卡挑战
- 文案：
  - 主标题：**冰爽水果碗**
  - 副标题：**一捞一爆款**
- 画面要点：
  - 中央一只大号鸳鸯/酸奶大碗（紫白渐变奶基底），碗里**铺满冰块块（六边形 / 方形冰块，半透明蓝白）和五彩水果切片**，画面中部三块冰相同水果碰撞炸开、金光与水果颗粒飞溅。
  - 旁边漂浮少量小道具图（小扫帚 / 加菜牌 / 打乱箭头）作为玩法暗示，但不写按钮文字。
  - 整体冷暖对比：冰块冷调 + 水果暖调，营造"清爽解压"。
