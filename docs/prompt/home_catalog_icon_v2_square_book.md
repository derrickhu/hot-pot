# 首页图鉴入口图标 v2（正方形按钮底 + 简化书本）

Generate one single square game UI icon button for a mobile casual fruit game home screen.

Use the provided home screen screenshot as style reference. The icon is for the fruit catalog / collection entry and will sit to the right of the main level button.

## Content

- One rounded square button background.
- On top of the square button: one simple closed or slightly open fruit book / album icon.
- The book should be clear at small size:
  - thick dark teal outline
  - simple cream pages or cover
  - one large fruit mark on the cover/page, such as a strawberry or lemon
- Keep the book simple, with very few details.
- No text, no Chinese characters, no English letters, no numbers.

## Shape

- Rounded square button, not a long rectangle, not a pill.
- The square button background should be visible and obvious.
- The book should be centered and occupy most of the square button.
- Icon composition should read clearly at about 70-90 px in game.

## Style

- Cute 2D casual mobile game UI matching the "别捞水果" home screen.
- Same soft glossy / hand-painted feeling as the green level button.
- Use limited colors only:
  - soft mint / pale blue square button background
  - dark teal outline
  - cream book
  - one red or yellow fruit accent
- Do not use too many page drawings, tiny fruits, tiny labels, or complex decorations.

## Output

- Transparent background PNG if supported.
- Only the rounded square icon button, no outside label, no extra text, no watermark.
