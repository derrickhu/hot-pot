# banana_1 重生：厚圆片，换角度（对齐 banana_2）

## 用户要求

- **与 banana_2 同款**：厚圆片（短圆柱切片），可见顶面圆切面 + 侧面厚度
- **仅换视角/旋转**：例如更侧视、或绕竖轴转约 30°~45°，与 banana_2 不要同角度
- **禁止**：长弯香蕉段、整根香蕉、拖影、拉伸、涂抹、形变

## 画风（v2）

- 手游水果碗 2.5D 插画：平滑渐变 + 左上高光 + 侧面略深
- 顶面：乳白/淡黄果肉，中心五角星芯 + 深褐小籽
- 侧面：金黄果皮，细竖纹，同色深描边（无黑粗边）
- 参考图：`banana_2.png`（厚度、圆片比例、质感以此为准）

## 构图

- 单枚主体居中，白底 `#FFFFFF`
- 圆片直径约为画面短边的 55%~70%；**厚度明显但短**（高:直径 ≈ 0.35~0.5），不要细长条
- 四角留白充足，顶面尖角/边缘完整，勿裁切

## 输出

- 1 张 PNG，后续 rembg → trim → 等比缩放到最长边 168px → `banana_1.png`
