# 首页「果切挑战」按钮贴图 v4（橙色、带字、刀切西瓜图标）

Generate one single game UI button asset for the home screen entry "果切挑战".

Use the provided screenshot as the main visual reference. The new button must match the exact UI language of the green "第1关" level button above it, but use an orange color theme.

## Required Content

- One orange rounded pill button only.
- The button must contain, from left to right:
  1. A small cute icon showing a knife cutting a watermelon slice.
  2. Exactly these 4 Chinese characters: **果切挑战**
- The text and icon must be generated as part of the image.
- The Chinese characters must be complete, correct, centered vertically, and clearly readable.
- No other text, numbers, English letters, logos, watermarks, extra icons, or decorations.

## Shape And Layout

- Same proportions as the referenced "第1关" button: wide capsule, soft rounded ends, about 3.3:1 to 3.6:1 width-to-height ratio.
- The icon should sit just before the text, with comfortable spacing, like a polished mobile game CTA button.
- Keep the whole icon + text group visually centered inside the button.
- Keep transparent padding around the button edge for later cropping.

## Style Match

- Cute 2D casual mobile game UI, hand-painted, soft and polished.
- Match the "第1关" button style closely:
  - same soft glossy top highlight
  - same smooth rounded capsule volume
  - same medium-thick dark teal / blue-green outer outline
  - same thin bright inner rim
  - same friendly rounded Chinese font weight and outline style
- It should look like the orange sibling of the green "第1关" button, not a different heavy 3D gold button.

## Color

- Orange theme, but keep it soft and UI-consistent:
  - top: warm light peach / light orange
  - bottom: saturated tangerine orange
  - avoid red-orange heaviness, metallic gold, harsh shadows, or very dark gradients
- Outer outline: dark teal / blue-green, matching the "第1关" button outline rather than brown.
- Text: cream / very light yellow fill with dark teal outline, matching the readable style of "第1关".
- Icon colors should be clean and cute: red watermelon flesh, green rind, small silver knife, all with dark teal or dark warm outline.

## Output

- Transparent background PNG if supported.
- The final image should contain only the button with baked-in knife-watermelon icon and "果切挑战" text.
- Clean edges, no scene background, no fruit background decorations, no drop shadow outside the button.
