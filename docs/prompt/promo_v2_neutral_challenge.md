# 别捞水果 · v2 中性挑战风（1 竖 + 1 横）

## 设计方向（与 v1 的区别）

| 维度 | v1（已有） | v2（本次） |
|---|---|---|
| 受众感 | 偏女性 / 治愈 / 可爱 | **中性休闲手游风**（开心消消乐 / Royal Match 类） |
| 调性 | 奶油黄 / 薄荷 / 粉嫩 | **饱和 sapphire 蓝 + 金黄 + 红橙 + 暗紫**对比强 |
| 角色 | 小厨师女孩 | **无人物**，主体只有水果碗 + 玩法元素 + 关卡数字 |
| 主推卖点 | 玩法 / 解锁 / 收藏 / 治愈 | **关卡多、挑战难、通关爽**（数字 / 奖杯 / 三星 / COMBO） |

## 风格守则（共用）

- 画面风格：**polished casual mobile match-3 ad key art**（开心消消乐 / Toon Blast / Royal Match / 梦幻花园），饱和、冲击、有"刚通关"瞬间感，**不**奶油可爱、**不**手账软糯。
- 配色：sapphire 蓝、金黄、红橙、暗紫、银白冰、薄荷绿点缀（少量）。
- 描边：保留卡通厚黑/深褐外描线 + 金黄描边强化。
- **禁止**：女性 mascot / 厨师帽 / 奶油色卷轴可爱字 / 飘落樱花花瓣 / 奶咖背景；写实摄影、硬 3D、UI 按钮文字、应用商店徽章、文字、Logo、二维码、手机框。
