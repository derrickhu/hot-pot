# 首页超值礼包弹窗 v5（整图含文案道具，按钮留空）

参考原型：霓虹灯框 + 金红顶栏 + 道具格 + 绿色空按钮（程序叠广告计数）。

## 必须出现的中文（逐字准确）

- 顶栏主标题：**超值礼包**（四字，粗大金红渐变描边）
- 顶栏副标语：**清爽消除 · 道具拿到手软**
- 内容区横幅：**礼包总价值 超300金币!**（不要写 6000，不要「10倍」任何字样）
- 小标题：**5种道具+100金币**
- 道具格（含图标+数量）：
  - 加菜碟 x2 | 移除 x2 | 打乱 x2
  - 消除 x2 | 打乱 x2
  - 金币 x100（居中）
- 左侧飘带：**限时领取**
- 右侧飘带：**通关必备**
- 底栏小字：**— 机会难得 错过不再! —**

## 禁止

- **禁止**出现「10倍」「超级返利」「新手大礼包」「6000」
- 底部绿色大按钮：**禁止任何文字**（留空给程序叠「▶ 0/2」）
