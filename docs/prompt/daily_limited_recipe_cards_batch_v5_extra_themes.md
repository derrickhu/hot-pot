# Daily Limited Recipe Cards Batch v5 Extra Themes

目标：为每日限定新增 6 个主题重新生成菜谱卡。不能使用用户给的截图作为素材，只从截图识别主题方向和制作内容，按现有每日限定菜谱卡统一规范重新生成。

## 固定风格

- 9:16 竖版。
- 参考 `subpackages/bowl_game/assets/images/daily_limited/recipes/pineapple_sprite_slush_recipe_card_v3.png` 的整体风格。
- 圆角内卡、顶部大标题、短副标题、上半区饮品插画、中部准备材料、下半区 2 列步骤卡片。
- 可爱手绘插画 / 轻 UI 图标风，不能写实，不能照片风，不能硬 3D。
- 中文字符必须完整、清晰、可读。
- 配色和装饰可按主题变化，但版式统一。

## 新增主题

1. 芭乐牛油果奶昔：目标芭乐、牛油果。
2. 黄瓜雪梨汁：目标黄瓜、雪梨。
3. 荔枝火龙果饮：目标荔枝、火龙果。
4. 梅渍小番茄：目标小番茄、话梅（资源暂用 sour_plum）。
5. 石榴冰茶：目标石榴。
6. 杨梅荔枝饮：目标杨梅、荔枝。

## 追加修正

- 梅渍小番茄目标水果改为只有小番茄，不再展示话梅目标图标。
- 追加主题：杨梅瑞纳冰，目标水果只有杨梅。
- 杨梅瑞纳冰制作方法需精简易懂：
  1. 杨梅去核切碎，喜欢颗粒感可切粗一点。
  2. 杨梅加冰糖、白砂糖和柠檬汁，小火熬成果酱。
  3. 另取杨梅冷冻后打成细碎沙冰。
  4. 杨梅沙冰加入杨梅酱和茉莉花茶，比例约三比一。
  5. 搅拌均匀，可加冰块让冰感更久。
