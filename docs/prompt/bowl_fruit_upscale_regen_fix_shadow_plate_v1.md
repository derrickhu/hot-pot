# 修复：阴影 / 盘子 问题 v1

## 原因
1. **游戏碗截图**作参考时，模型会连同碗、托盘、**落地阴影**一起画出来 → rembg 抠不干净。
2. 提示词里虽写了 NO shadow，但权重不如参考图里的碗场景。
3. 小料批次若参考图少，模型更容易「找个容器托住」→ 绿色方盘等。

## 抠图说明
- **理想母版**：纯白底 + 食材内部渐变 + **零外部阴影** → `birefnet-general` 一次即可。
- **有落地阴影**：灰影会被当成前景残留，或抠出毛边 halo。
- **有盘子**：盘子与食材连在一起，无法自动只留小料 → **必须重生成**，不能靠抠图修。

## 新规则（v2 脚本已更新）
- 风格参考改为 **`mango_2.png`**（仅学立体感画法，不学场景）。
- 强制：无 drop shadow / contact shadow / 灰影椭圆 / 盘子 / 托盘。
- 小料额外禁止：方盘、瓷碟、碗沿。

## 需重生的合图
凡 raw 里出现阴影或盘子的批次，用新提示词重跑 GenerateImage，再切格抠图。

已处理但 raw 有问题的：优先看 `raw/duo_*` 小料与带灰影的水果批次。
