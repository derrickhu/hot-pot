# 果切玩法专属分享卡 v1

## 用途

微信小游戏转发卡片，专门用于果切无尽玩法的新记录分享按钮。

## 规格

- 横向 5:4 构图，最终输出 `1000×800` JPG。
- 画面需要适合作为微信分享卡，主体清晰、对比强。

## 画面

- 夏日水果游戏风格，2D 休闲手游插画，不要写实。
- 中央是一把锋利的横向菜刀 / 水果刀高速切过水果，刀刃有白色高光和速度线。
- 橙子、柠檬、西瓜、草莓、蓝莓、香蕉等水果被切开，果汁、切片、闪光四散。
- 背景是清爽蓝天和柔和云朵，整体明亮、有挑战感。
- 顶部大标题文字：**果切无尽**
- 副标题文字：**一刀连切，挑战新记录**

## 禁止

- 不要二维码、水印、英文、排行榜、按钮、手机壳。
- 不要使用旧水果捞文案。
