# 首页「果切挑战」按钮贴图 v2（与关卡药丸同扁平度、淡黄色、带字）

## 用途

微信小游戏首页，与「第 N 关」所用 `home_play_btn.png` **同一扁平休闲度**：**不要强烈立体、鼓包、厚玻璃高光**；整体偏**扁平 + 柔和微渐变**，像同一套 UI 里换色的第二颗主按钮。

## 文字（必须画在图上）

- 按钮中央 **必须且仅能** 出现下面 **4 个汉字**，字形完整清晰：  
  **果切挑战**
- 字体：粗圆黑 / 综艺圆体感，与绿色关卡按钮上的「第 N 关」气质接近（可爱、略粗、易读）。
- 字色：略深的暖棕或橄榄绿描边 + 米白 / 淡奶黄填色（保证在淡黄底上对比足够）。

## 色彩与形体

- 药丸形圆角横条，**宽高比约 3.4:1**（与关卡按钮同量级，约 880×260 像素级别即可）。
- 底色：**淡黄色**为主（例如奶油黄、柠檬雪纺），**上下极轻的渐变**（上略亮、下略深即可），不要大块高光条、不要内阴影鼓包。
- 外框：**中等粗细描边**（草绿、橄榄绿或暖棕），风格与关卡绿按钮的描边力度接近，**不要**金属反光、不要厚 3D 倒角。

## 禁止

- 强烈 3D、凸起塑料、玻璃釉大高光、内发光厚立体
- 除「果切挑战」四字外任何其他文字、数字、英文、Logo、水印、小图标
- 与关卡按钮完全同色的绿色底（本按钮为淡黄系）

## 输出

- 透明背景 PNG，仅一颗按钮 + 四字。
