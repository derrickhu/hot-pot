# 每日限定玩法冰碗资源 v1

## 用途

每日限定玩法中用于承接目标水果片的冰碗。碗底需要有碎冰 / 冰块托住水果，避免水果图标放进去时像沉到底部。

## Gemini 提示词

```text
Single game UI asset: an elegant transparent glass dessert ice bowl for a cute 2D casual mobile fruit game.

Style:
- Polished 2D hand-painted cartoon game asset, clean outline, soft cel shading.
- Same art family as a bright summer fruit dessert puzzle game.
- Not photorealistic, not 3D render, not anime character art.

Object:
- One transparent pale-cyan glass compote bowl, viewed from a slightly top-front angle.
- The bowl has a rounded scalloped rim, faceted glass sides, short pedestal foot, and soft white rim highlights.
- Inside the lower half of the bowl: a visible bed of crushed ice and several cute semi-transparent ice cubes.
- Ice cubes should sit at the bottom and mid-lower area, leaving clear open space above for fruit slices to be placed later.
- The ice should look supportive, sparkling, and cool, not like water only.
- Add subtle caustic sparkles, condensation highlights, and soft blue shadows inside the glass.

Composition:
- Centered single object, large, front-facing enough for UI use.
- Bowl should fit nicely in a square icon / UI slot, with a little transparent margin.
- White or very pale simple background is OK for background removal, but the final object must be easy to cut out.

Strict constraints:
- Generate only one bowl.
- NO fruit, NO spoon, NO straw, NO table, NO text, no labels, no logo, no watermark.
- No busy background, no scene, no UI panel, no cards, no buttons.
```
