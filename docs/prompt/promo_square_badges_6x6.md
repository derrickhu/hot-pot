## 风格基线

参考已有 30 枚关卡徽章 `assets/final/badges_birefnet/bowl_badge_01.png ~ 30.png`：

- Q 版手绘卡通休闲游戏图标风
- **每枚徽章一只玻璃杯 / 透明杯 / 圆碗 / 异形杯** 装一份清凉水果甜品/饮品
- 厚白软描边围着饮品 + 一圈柔和淡彩 sticker badge 边框
- 配料丰富：冰块 / 薄荷 / 水果 / 珍珠 / 椰果 / 奶盖 / 果冻 / 爆珠 / 银耳莲子等
- 高饱和柔和夏日色：水蓝、柠檬黄、草莓粉、芒果橙、薄荷绿、葡萄紫
- 不要文字、数字、Logo、水印；不要现实摄影；每格只画一枚完整徽章；不裁切

## 6×6 排版要求

- 整图 1:1，布局 **6 列 × 6 行**，36 个等大方格。
- 每格中央 1 枚徽章，徽章占格高 ~75%，四边留足白边以便后续 3×3 切分不切到主体。
- 整图四周再留 ~3% 安全留白。
- 整图背景：**柔和奶油色 / 浅奶咖渐变**（不要纯白），可加极轻微的小水果/星星点缀作底纹；**3×3 切分线（在 1/3、2/3 位置）必须落在格子之间的留白上**，不要让任何徽章压线。
- 36 枚要做出尽可能多的差异：不同杯型（高玻璃杯 / 矮厚碗 / 椰子壳 / 高脚杯 / 木桶 / 小冰沙杯 / 奶盖杯 / 锥形冰沙杯 / 火山刨冰碗 / 鱼缸杯…）、不同主色、不同水果与配料组合。
