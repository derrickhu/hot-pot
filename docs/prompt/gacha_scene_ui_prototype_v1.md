# 金币扭蛋 GachaScene UI 原型图 v1

目标：为游戏中的「金币扭蛋」活动页设计一张 **完整可落地的高保真 UI 原型图（mockup）**，
风格与首页 / 果切挑战 / 关卡场景统一（明亮夏日卡通水果、圆角厚边框、POP 字标题），
并且页面要有 **强烈的"抽奖、随机、惊喜"** 感觉，
中央的 **扭蛋机本体要做成全图视觉中心**，且后续可以接帧动画
（晃动、扭把转动、蛋滚出、爆光闪）。

## 输出参数

- **比例**：9:16 竖版 mobile game UI mockup（生图后再 conform 不影响原型用途）
- **目标用途**：内部 UI 原型 / 视觉对齐参考。**不进游戏包**，落到 `game_assets/hot-pot/assets/raw/`。
- **图像尺寸**：1K（1024 级别）即可
- **模型**：`gemini-3.1-flash-image-preview`（NB2，中文标题字稳）

## 整体版式（自上而下）

整张画面是一台手机内的 UI 截图原型，外面 **不要** 加任何 phone frame / device mockup。
背景沿用游戏现有 home 一样的暖色系：奶油黄底 + 阳光斑、远景水果剪影点缀、不要写实摄影感。

整体分 5 个层次，从上到下：

1. **顶部状态栏区**
   - 左上：圆角胶囊「← 返回」按钮，浅黄色，带卡通厚描边。
   - 顶部居中：大字标题 "金币扭蛋"。
     - 主标题字风：thick strokes / **bright YELLOW fill** / **RED-ORANGE outline** / **dark brown outermost outline** / soft drop shadow / slightly bouncy baseline（"叮咚 POP 体"）
     - EXACTLY four characters: 金币扭蛋
   - 右上：金币余额胶囊条，与游戏内一致：左侧圆形金币图标（中心五角星，金黄色），右侧白色描边数字 "5"。

2. **主视觉装饰带**（标题与扭蛋机之间）
   - 横向悬浮一条彩色 "?" 问号气泡 + 星星 + 闪光，营造惊喜氛围。
   - 两侧飘几颗微小水果剪影（草莓 / 柠檬 / 蓝莓），淡化半透明，作为"随机奖励"暗示。

3. **中央扭蛋机本体（占整张图垂直 ~45%，是绝对视觉重心）**
   重点设计如下，要做到"看一眼就想点"：
   - **整体形态**：胖一点的卡通糖果机，比例像 1.0 : 1.4 高宽比，圆角厚白描边 + 深一档色描边（参考 huahua 同款双层描边）。
   - **机身配色**：糖果红 (#ff5b6f) 底 + 顶部黄色三角小帽（像马戏团帐篷顶），底座暖橙 (#ffb44a) + 反光高光。
   - **顶部装饰**：机身两侧一对小金色旋钮、机顶中央一颗五角星金币 logo（与本游戏金币图标一致：星星嵌在金币里）。
   - **玻璃球（机身上半部分，最关键）**：
     - 浅蓝青色玻璃球 (#b7f1ff)，带 6pt 白描边，左上 1/4 处一道大斜白色高光，右下一道弧形阴影。
     - 球内塞满 18~24 颗 **彩色扭蛋胶囊球**，颜色不重复、亮丽（柠檬黄、薄荷绿、樱桃粉、天空蓝、橘子橙、葡萄紫、玉米奶白）。
     - 部分扭蛋表面印有小 logo（金币图标 / 星星 / 雪花 / 闪电），暗示"道具/稀有"。
     - 几颗高光提亮的"闪光球"在球堆顶部，营造"刚摇晃完"的随机感。
     - 球与球之间有轻微挤压、不要排得整齐，要有"自然落入"的随机姿态。
   - **机身中段**：贴一张 "GACHA" 横向条带 / 或者中文 "扭蛋" 两个字大字（EXACTLY two characters：扭蛋），同款 POP 字风，
     **以中文为准**，避免英文。
   - **底部出蛋口**：暖黄底盘 + 一个圆形透明半窗（露出一颗即将弹出的金色蛋），半窗下方有一个明显的 **横向凹槽出蛋口**。
   - **右侧扭把（关键交互暗示，便于做动画）**：一个金色小旋钮 + 一根 12 点钟方向的把柄，把柄末端有红色小球。
     画面里把柄略微向 1 点钟方向倾斜，暗示"可以转"，旁边浮一个小小的旋转箭头（顺时针半圈 + 闪光小线）。
   - 整台机器底部投一道椭圆深色阴影 + 几颗向上飞起的星星 / 火花，强化"刚摇过 → 即将出蛋"的瞬间感。

4. **抽奖按钮区（机器正下方）**
   - 主按钮：圆角加粗药丸按钮，暖橙 → 蜜糖渐变 (#ff8c3c → #ffc466)，厚描边 + 阴影 + 内描边高光。
   - 按钮上面写 EXACTLY five characters: 抽一发！
     - 同样 huahua POP 字风（黄填红描棕外描）。
   - 按钮右上贴一枚小金币 + 数字 "20"，表示消耗（不要写"金币"二字，靠图标传达）。
   - 按钮下方一行小字 EXACTLY twelve characters: 金币来自果切挑战返利
     - 米色字 / 棕色描边，弱化但易读。

5. **底部奖池预览区（增强"想抽"的欲望）**
   - 横向一排 5~6 个圆角白底卡片，每个卡片里展示一个可能获得的小奖品图标 + 上方一颗星标（稀有度示意）：
     - 道具示意图：彩色锤子 / 小炸弹 / 旋风刷 / 雪花冰冻 / 金色礼盒 / 水果切片 等卡通道具，与本游戏「果切消除/打乱」「关卡道具」氛围一致。
     - 卡片整体偏小、半透明叠在 UI 最底，避免抢扭蛋机视觉。
   - 在奖池上方一行小字标题 EXACTLY four characters: 可能获得（白底 / 棕字）

## 严格约束

- **生成且仅生成**这些中文字符串，逐字保留笔画、字号匹配版式：
  - "金币扭蛋"（顶部标题）
  - "扭蛋"（机身中段）
  - "抽一发！"（主按钮）
  - "金币来自果切挑战返利"（按钮下方说明）
  - "可能获得"（奖池标题）
  - "5"（金币余额数字，可替换为占位）
  - "20"（按钮金币消耗，可替换为占位）
- 不允许出现：英文字母（除非是 GACHA 这种装饰字，且不强制）、QR code、二维码、watermark、app store badge、对话气泡、聊天框、外框设备 frame、photoreal 摄影感。
- **不允许**：再画一道外框（顶部状态栏不需要 phone notch）。
- 单一连贯插画，元素相互呼应，不要拼贴感。

## 备注（用于后续帧动画规划）

原型图定稿后，**扭蛋机** 计划拆出独立精灵，做以下几段帧动画（多针 / sprite sheet）：

1. **idle**：玻璃球内胶囊轻微浮动 + 星星闪烁（loop）。
2. **shake**：机身左右抖动 5~6 帧 + 胶囊在球内剧烈翻滚（按下抽奖时播 0.6~0.8s）。
3. **drop**：底部出蛋口弹出一颗金色胶囊 + 星星迸发（0.4s）。
4. **glow burst**：稀有度高时罩一层环形光线 + 闪屏（叠加播）。

因此原型图里 **机身、玻璃球、胶囊、把柄、出蛋口** 必须是清晰可拆分的独立结构，
不要互相穿插或被装饰物遮住，方便后续按图层切片。
