# 桑葚 / 杨梅 单颗重生（对齐上午 v2 合图风格）

## 风格锚点

- `final_v2_bad/mulberry__nectarine/mulberry_1.png`
- `final_v2_bad/bayberry__blackberry/bayberry_1.png`
- 立体感参考：`mango_2.png`

## 画风（不要太扁、不要太写实）

- 手游水果碗 **2.5D 插画**：平滑渐变 + 左上高光 + 侧面深色
- 杨梅：每颗小凸起各有一粒高光；桑葚：每粒 drupelet 高光
- **描边** = 比主色深一档的紫/酒红，不要纯黑
- 禁止：照片质感、过简扁平矢量、碗/盘子/落地阴影

## 数量

每格 **一颗**，不要三颗串。

| ID | 内容 |
|----|------|
| mulberry_1 / _2 | 单颗桑葚，两格仅旋转角度不同 |
| bayberry_1 | 单颗整颗杨梅 |
| bayberry_2 | 单颗切半杨梅（露籽） |

白底 `#FFFFFF`，GenerateImage 后 rembg → 缩放进包。
