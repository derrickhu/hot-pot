# 首页大礼包弹窗面板 v1（无字母版）

用途：`HomeMilestoneGiftPanel` 底图；标题、副标题、道具图标、按钮文字均由程序叠加。

## Prompt

Vertical mobile game reward popup panel, portrait orientation ~3:4.

Style: cute casual fruit puzzle game, premium "super rich loot" feeling, glossy 2D cartoon with soft cel shading and gold accents — match bright summer fruit game UI. NOT photoreal, NOT 3D render.

Main panel:
- Large rounded rectangle card, cream-ivory interior (#FFF8E8), thick polished gold border with inner glow, subtle sparkle stars and tiny gem highlights on corners only.
- Top center: decorative title banner ONLY — red-orange ribbon tails left/right, golden plaque in center with beveled edge. The plaque must be EMPTY blank surface for later text overlay (absolutely NO letters, NO Chinese, NO numbers on plaque or ribbon).
- Below banner: generous empty cream content area (about 65% of panel height) completely blank — this is where game will place reward item icons. NO items, NO icons, NO coins drawn in content area.
- Bottom: reserved empty strip (~18% height) with subtle golden frame hint for a button placement area, but do NOT draw a button inside the panel image.

Luxury details: soft radial light from top, faint confetti sparkles along top edge, rich warm gold (#FFD95A) + coral accents (#FF6A4A), feeling expensive and abundant.

Background: fully transparent outside the panel silhouette (no full-screen backdrop, no outer dim).

Constraints:
- NO text, NO letters, NO numbers, NO watermark, NO logo anywhere.
- Single cohesive UI asset, centered on canvas.
