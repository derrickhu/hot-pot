## 画面设计（横版 540×276 卡片）

- **背景**：薄荷青 → 浅海蓝渐变，**淡淡的椰子树叶剪影**作底纹（不要太抢主体）。
- **左侧**（约 40%）：一只**白色卡通卡片 / 小招牌**，朝向斜放，正面贴一张**金黄+红描边**的"鲜果一夏"中文标题（4 字一行）；下方一行小一点的"清凉上头"（4 字）红描边白底。卡片边缘可点缀小草莓 / 柠檬片。
- **中右**（约 60%）：一只**清凉夏日水果碗**——透明玻璃碗 / 浅椰白底，盛放**热带 + 清凉混搭**水果切片（菠萝块、芒果丁、西瓜角、猕猴桃片、橙片、蓝莓、草莓），上面盖着几块**半透明蓝白冰块**，碗口飘出**薄荷叶 + 一根小纸伞**。碗后面斜插一片**大棕榈叶**剪影，营造海岛感。
- **氛围**：阳光从右上洒下，金光斑驳；周围漂浮 2~3 颗水果切片粒子、几个小冰晶、几滴水珠；不要爆炸星芒、不要电光（与 v2 区分）。
- **不要**：人物、UI 按钮、应用商店徽章、文字（除上述两行中文标题）、二维码、相框边框、奶咖背景。

## 安全区强调

- 540×276 上下边各裁 ~5%；prompt 必须明示主体（碗 + 标题卡片）在画面中央 90% 区域内，**不贴顶不贴底**。
