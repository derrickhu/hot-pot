## 石榴冰茶

- 标题：石榴冰茶
- 副标题：红宝石果粒冰茶
- 材料：石榴、柠檬、茉莉茶、蜂蜜、冰块
- 步骤：
  1. 石榴剥出果粒
  2. 轻压挤出果汁
  3. 加入柠檬片
  4. 倒入茉莉茶
  5. 蜂蜜调甜味
  6. 加冰完成

## 杨梅荔枝饮

- 材料：杨梅、荔枝、柠檬、薄荷、冰糖
- 步骤：
  1. 杨梅盐水浸泡
  2. 加水煮出果汁
  3. 加入冰糖调味

  5. 倒入杨梅汁
  6. 加冰点缀完成
