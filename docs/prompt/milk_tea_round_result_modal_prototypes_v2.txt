Create a 3-panel UI prototype sheet for a cute mobile milk tea puzzle game result flow.

Important design update:
- Do NOT use EXP / experience bars / experience points anywhere.
- Shop progression is based on completed rounds.
- Use short messages like "再完成 2 局升级" or "再完成 1 局升级".
- Keep information simple, immediately understandable, and visually attractive.

Canvas and layout:
- One wide image with 3 vertical mobile modal mockups side by side.
- Each panel shows the same blurred milk tea puzzle board background behind a centered rounded result card.
- Soft 2D casual mobile game UI, warm cream and honey colors, boba tea decorations, polished cute style.
- This is a visual prototype sheet, not final production art.

Panel 1: Round Clear Result
- Mood: happy and simple.
- Main title: "恭喜过关"
- Primary reward row: gold coin reward, e.g. "金币 +38", with a shiny coin icon.
- Shop progress hint row: "再完成 2 局升级" with a small shop badge / checklist icon.
- If possible, include a tiny "本局完成 +1" visual cue, but keep it secondary.
- One primary orange button: "继续营业"
- Layout priority: title > coin reward > next-level round-count hint > button.
- No EXP text, no progress bar.

Panel 2: Shop Level Up
- This page appears after closing Panel 1 when the shop leveled up.
- Mood: more celebratory, stronger glow, confetti, sparkle.
- Main title: "店铺升级"
- Show level change clearly: "Lv.3 → Lv.4"
- Show a "new unlocked drink" area with one or two cute milk tea cup icons on small cards.
- Optional text area: "新饮品解锁"
- One primary button: "太棒了"
- Layout priority: title > level change > unlocked drinks > button.
- No EXP text, no progress bar.

Panel 3: Fail / Revive
- Mood: gentle, not punishing.
- Main title: "空间满了"
- Short explanation: "棋盘没有空位啦"
- Show a small board icon with crowded trays.
- Two buttons:
  - Secondary button: "重开一局"
  - Primary green/orange button: "清空复活"
- Include a small revive description area: "清空棋盘托盘，继续本局"
- Layout priority: reason > visual hint > two clear choices.

Visual constraints:
- Keep all cards clean and readable.
- No dense paragraphs.
- Large rounded card, cream fill, honey-orange border.
- Use icon rows, badges, coins, drink cards, and sparkles to make it appealing.
- Chinese text should be short and large, but exact text quality is not critical for prototype.
- No app store badges, no watermark, no logo, no QR code.
