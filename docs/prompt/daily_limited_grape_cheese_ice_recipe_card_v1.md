# Daily Limited Recipe Card - 多肉葡萄 v1

目标：生成一张每日限定玩法解锁用的「多肉葡萄」图文制作方法卡。

识别自参考图的制作方法摘要：

- 标题：多肉葡萄
- 标语：清甜多汁，果香浓郁，夏日必备
- 食材准备：
  - 葡萄 15-20 颗
  - 柠檬片 2-3 片
  - 茉莉花茶 100ml
  - 蜂蜜或糖浆 适量
  - 冰块 适量
- 制作步骤：
  1. 处理食材：葡萄对半切开，去籽后放入杯底
  2. 加入柠檬片：杯中加入柠檬片，增添清新口感
  3. 倒入茶汤：倒入冷却后的茉莉花茶，茶香更清爽
  4. 加入糖浆：加入适量蜂蜜或糖浆，搅拌均匀
  5. 加入冰块：放入冰块，轻轻搅拌即可享用
