# 碗与汤底解锁规划

## 目标

- 保留第 1 关默认资源：水晶碗 + 奶白汤。
- 30 关内持续给玩家新鲜感：前期快速出现第一个新汤底，中期交替解锁碗和汤底，后期仍有高级外观。
- 碗与汤底只改变视觉主题，不改变玩法数值；订单、食材池和障碍逻辑仍由关卡配置控制。

## 素材规格

- 汤底：`1024x1024`，顶视正圆液面，圆外纯 `#FF00FF`，后处理去底并按正圆裁切。
- 碗：`1024x1024`，顶视正圆碗沿，内圈和背景纯 `#FF00FF`，后处理去底并生成透明碗口。
- 原始图与中间产物放在 `/Users/rosa/rosa_games/game_assets/hot-pot/assets/`。
- 确认后再复制进 `subpackages/bowl_game/assets/images/`，建议命名：
  - `bowl_soup_<key>.png`
  - `bowl_rim_<key>.png`

## 后续接入

- 在 `src/config/bowlLevels.ts` 的 `soupKey` / `bowlKey` 填入对应 key。
- 在 `BowlScene` 中根据当前关卡 key 加载对应汤底和碗沿贴图；未配置时回退到 `milk` / `crystal`。
- 图鉴或结算页如要展示新外观，可复用同一解锁表。
